## How I Ship / 我怎么做产品

1. **Find — 定义问题**：先看真实场景、现有流程、证据缺口与非 AI 基线。
2. **Build — 做成产品**：把判断落成可运行的网站、交互产品或 Agent Skill。
3. **Eval — 验证边界**：用任务集、bad case、永久事实与安全规则测试效果。
4. **Ship — 留下证据**：公开产品入口、源码、评测材料、限制与下一步验证。

## Product Depth / AI 产品底色

- **产品 × 交付**：从问题定义、PRD、交互到实现、上线与复盘。
- **Agent × 工作流**：把复杂任务拆成可复用、可验证、能安全降级的 Skills。
- **评测 × 证据**：区分事实、推断与未知，不用漂亮结果掩盖尚未验证的边界。
- **体验 × 内容**：探索叙事、城市体验、信息产品与多模态交互的产品化方式。
